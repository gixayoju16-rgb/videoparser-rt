# 视频信息解析 — 运行时包

配合 **视频信息解析 (com.operit.videoparser)** 使用。

## 用法

在 App 的 `设置 → 境外站点下载` 下方地址栏填入：

```
https://github.com/gixayoju16-rgb/videoparser-rt/releases/download/v1
```

然后按需点三个按钮下载：

| 文件 | 用途 |
|---|---|
| core.zip | Python + yt-dlp（B站/TikTok 等必需） |
| yt.zip | deno + PoT（YouTube 高清需要） |
| ffmpeg.zip | ffmpeg/ffprobe（画面+音频混流需要） |
